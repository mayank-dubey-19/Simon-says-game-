# Simon-says-game-
🎯 Simon Says (Color Memory Game) Simon Says is a fun memory challenge where the player must repeat a growing sequence of colors in the exact order. Each round, the game flashes a color pattern — starting with one color — and adds a new color each time the player gets it right.
